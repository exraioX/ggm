Como ativar no Claude Code

Não é necessário instalar um plugin ou enviar os arquivos para uma API.

  1. Clone o repositório e entre na pasta raiz do projeto.
  2. Inicie o Claude Code nessa pasta para que ele encontre .claude/skills/.
  3. Use um dos comandos acima, por exemplo /research-design.
git clone --branch llp --recurse-submodules https://github.com/exraioX/ggm.git
cd ggm
claude
As skills orientam o fluxo de trabalho do Claude Code; elas não executam experimentos por conta própria. A execução e o armazenamento dos testes são feitos pelo Research Lab no GODMODE CORE. Revise skills de terceiros antes de instalá-las.
