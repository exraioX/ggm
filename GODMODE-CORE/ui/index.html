          Como usar o OmniRoute com o GODMODE
          

            
    
              
  1. Instale o gateway no terminal: npm install -g omniroute.
    2. 
              
  2. Inicie com omniroute e abra http://127.0.0.1:20128.
    3. 
              
  3. No painel do OmniRoute, conecte os provedores que deseja usar e crie uma chave em Endpoints.
    4. 
              
  4. Clique em Conectar OmniRoute aqui, cole essa chave e salve. O GODMODE usará http://127.0.0.1:20128/v1.
    5. 
              
  5. No Chat, selecione OmniRoute e escolha auto, auto/coding ou um modelo/provedor listado por ele.
    6. 
            

            
O OmniRoute é um serviço separado: precisa estar aberto para rotear as chamadas. A chave do gateway fica em memória no núcleo e precisa ser inserida novamente após reiniciar o GODMODE, salvo se você configurar outro método de credencial.
